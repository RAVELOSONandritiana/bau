Centre d'aide

Apprenez à utiliser efficacement la bibliothèque numérique

Comment effectuer une recherche

1. Recherche globale

Le champ "Rechercher..." permet de rechercher simultanément dans le titre, l'auteur, la description et les mots-clés des ouvrages.

Exemple : Tapez "Madagascar" pour trouver tous les livres mentionnant Madagascar dans n'importe quel champ.

2. Recherche par champs spécifiques

Titre du livre

Recherchez un ouvrage par son titre exact ou partiel.

Nom de l'auteur

Trouvez tous les ouvrages d'un auteur spécifique.

Mots-clés

Séparez plusieurs mots-clés par des virgules pour affiner votre recherche.

3. Filtrer par période

Utilisez les champs "Année : Début → Fin" pour limiter les résultats à une période spécifique.

Astuce : Laissez le champ "Fin" vide pour rechercher tous les ouvrages à partir d'une année donnée.

4. Choisir la base de données

Sélectionnez la collection dans laquelle effectuer votre recherche :

  • • Toutes les bases : recherche dans toutes les collections
  • • P.A.MA.L : Périodiques Anciens déposés à la Bibliothèque et Archives Universitaires
  • • BUTANA : Bibliothèque Universitaire d'Antananarivo
  • • Livres : Bibliothèque et Archives Universitaires
  • • Fonds Grandidier : Collection sur l'histoire et la culture malgache

5. Nombre de résultats par page

Choisissez combien de livres afficher par page (10, 20, 30, 40 ou 50) pour faciliter la navigation.

Consulter les résultats

Trier les résultats

Utilisez le menu déroulant "Trier par" pour organiser les résultats par titre, auteur ou année, dans l'ordre croissant ou décroissant.

Filtrer rapidement

En haut de page, utilisez la barre de filtrage rapide pour affiner vos résultats par titre, description, auteur ou année sans relancer une nouvelle recherche.

Voir plus de détails

Cliquez sur "Lire plus →" pour afficher la description complète d'un ouvrage dans une fenêtre modale.

Accéder au document

Cliquez sur "Ouvrir le document →" pour consulter le PDF de l'ouvrage dans un nouvel onglet.

Questions fréquentes

Les collections présentes sur cette plateforme sont accessibles pour consultation en ligne, dans le but de promouvoir la culture et le savoir.
Actuellement, la plateforme est optimisée pour la consultation en ligne via notre visionneuse sécurisée. Cette mesure permet de garantir l'intégrité et la protection des droits de diffusion des documents.
Nous regroupons des fonds de différentes origines. Vous pouvez explorer les collections P.A.MA.L, BUTANA, Livres et le Fonds Grandidier, couvrant l'histoire et la culture malgache.
La précision historique est notre priorité. Si vous remarquez une inexactitude, vous pouvez nous contacter via les informations de contact situées en bas de page pour nous le signaler.

Conseils pour une recherche efficace

Soyez précis

Plus votre recherche est précise, meilleurs seront les résultats. Utilisez les champs spécifiques plutôt que la recherche globale.

Combinez les critères

N'hésitez pas à combiner plusieurs critères (auteur + année, titre + mots-clés) pour affiner votre recherche.

Utilisez le bouton Réinitialiser

Si vous voulez recommencer une recherche, cliquez sur "Réinitialiser" pour effacer tous les champs.

Essayez différentes formulations

Si vous ne trouvez pas ce que vous cherchez, essayez des synonymes ou des mots-clés alternatifs.

Besoin d'aide supplémentaire ?

Si vous rencontrez des difficultés ou avez des questions, n'hésitez pas à nous contacter.
